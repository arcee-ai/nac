# Experimental NAC client artifact (ALL-121)

This package is the revision-pinned, registry-free artifact used to prove the
ALL-121 ArceeFM journey. It is not the final packaging decision tracked by
ALL-122 and is deliberately marked private to prevent registry publication.

Install an exact reviewed NAC commit with npm:

```json
{
  "dependencies": {
    "@arcee-ai/nac-client-all-121": "https://codeload.github.com/arcee-ai/nac/tar.gz/<full-commit-sha>"
  }
}
```

Commit the resulting `package-lock.json`; npm records the exact source URL and
archive integrity. The root SDK has no runtime dependencies or install scripts. Optional React
peers are required only when importing the presentation subpath.
Its checked-in `dist/` output is built from `src/`, and its OpenAPI subset is
generated by NAC's existing `make generate-api-contract` writer.

The root export contains `NacClient`, `NacTransport`, `createNacApi`, the
command-admission and error contracts, snapshot/replay behavior,
`subscribeToSessionEvents`, the auth-capable `EventSourceFactory` seam, and the
transitive generated schemas required by the full resource facade.

`createNacApi(client)` exposes the same native resource methods as the web client:
projects/sessions, durable input/goals, permissions, child/orchestrator sessions,
workspace files/Git, providers/credentials, MCP/SSH, skills and managed product
resources. It uses the supplied transport's endpoint, headers and credentials;
it does not retry commands. `NAC_API_SURFACE` deliberately classifies all 123
documented OpenAPI operations. Generation rejects a missing or stale entry.
The liveness probe and server-owned outgoing OAuth callback remain private.
Undocumented managed control and legacy overview calls stay in the native web
adapter and are absent from this public facade.

The same private artifact now exposes the native React presentation through
`@arcee-ai/nac-client-all-121/presentation`, with explicit scoped CSS and an
asset manifest. The SDK root stays runtime-free. See the packed
[presentation guide](../nac-presentation/README.md) for consumer setup and the
repository's [native integration guide](../../../../../docs/api/native-presentation.md)
for lifecycle and verification boundaries. This bounded local export does not
publish a registry package or settle a stable package name/version policy.
