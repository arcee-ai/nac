# NAC Insights stack: screenshot comparisons

Before/after evidence for PRs #421–#431. Each frontend is the unmodified committed bundle at the exact base/head in manifest.json. Screenshots use deterministic local fixture responses driving real NAC tool execution in disposable workspaces, without production data or live model requests. Desktop captures use 1440×960 CSS pixels; phone captures use 390×844. Browser screenshots retain the browser/device scale.

Most frontend comparisons hold backend and session constant. The backend comparisons in #426 and #429 use the base binary (87faf08b) and a freshly built stack-tip binary (ea0d56ac), with identical fixture inputs; these are illustrative and do not claim exact per-layer backend qualification. The Files comparison uses an actual symlink type change and genuine merge conflict. #423 has no intended visual change. Active-run stills do not prove animation or scrolling stability. Read each PR's note for its particular state and limits.
